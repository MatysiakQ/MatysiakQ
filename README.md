## About me

I'm a junior developer who enjoys learning by building practical projects. I work mostly with web technologies, C# plugins for **SCP: Secret Laboratory**, and small experiments involving computer vision, automation and hardware.

I like turning ideas into working projects, improving existing code and learning new tools along the way. Some of my repositories are public, while other projects are private because they are connected with commercial work or are still in development.

## Featured projects

### 🤖 Robotic Hand Tracking Controller

A computer vision and robotics project created together with Łukasz Koszołko. It uses a webcam to recognize hand movement and translate finger movement into servo control for a physical robotic hand.

**Used:** Python, OpenCV, MediaPipe, NumPy, Raspberry Pi, PCA9685, LabVIEW and servo motors.

[View the project →](https://github.com/MatysiakQ/Hand-Tracking-Control-System--PUBLIC)

---

### 🚀 NextAI

A modern website for presenting AI agents, automation systems and digital solutions. The project focuses on responsive design, reusable components and a clear business-oriented user experience.

**Used:** Next.js, React, TypeScript, Tailwind CSS and Vercel.

- [Repository →](https://github.com/MatysiakQ/NextAI)
- [Live website →](https://next-ai.pl/)

---

### 🔫 FreshAmmoRules

A configurable ammunition management plugin for SCP: Secret Laboratory servers. It includes ammunition limits, extra ammunition for selected roles and live configuration reloading.

**Used:** C#, .NET 8 and EXILED.

[View the project →](https://github.com/MatysiakQ/JastrzabDEV--AmmoBalancer)

---

### 🧊 SCP Start Freezer

A plugin that temporarily freezes selected SCPs after spawning. I focused on configurable behavior and compatibility with Custom Roles and delayed role changes.

**Used:** C#, .NET and EXILED.

[View the project →](https://github.com/MatysiakQ/JastrzabDEV--ScpFreezer)

---

### 🏃 SCP Escape System

A gameplay plugin that gives SCPs and selected custom roles a way to escape the facility and changes the end-round logic depending on who escaped.

**Used:** C# and EXILED.

[View the project →](https://github.com/MatysiakQ/JastrzabDEV--SCPEscapeSystem)

---

### 🖨️ PRINTWALL

A business website for a wall-printing and large-format printing company. It includes a responsive presentation, portfolio section and contact form integration.

**Used:** HTML, CSS, JavaScript, PHP and Git.

[View the project →](https://github.com/MatysiakQ/JastrzabDEV--PRINTWALL)
