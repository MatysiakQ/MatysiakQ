## About

I am a junior developer working on web applications, C# plugins for **SCP: Secret Laboratory**, and smaller projects involving computer vision, automation and hardware.

A part of my work is public on GitHub. Other projects are private because they are commercial or contain code that cannot be shared. The public repositories usually contain project descriptions, screenshots, documentation and selected tools rather than complete source code.

I am still learning and developing my skills through practical projects.

## Selected projects

### 🤖 Robotic Hand Tracking Controller

A computer vision and robotics project created with Łukasz Koszołko. It tracks hand movement with a webcam and uses the results to control a physical robotic hand.

**Technologies:** Python, OpenCV, MediaPipe, NumPy, Raspberry Pi, PCA9685, LabVIEW and servo motors.

[Repository →](https://github.com/MatysiakQ/Hand-Tracking-Control-System--PUBLIC)

---

### 🚀 NextAI

A website for presenting AI agents, automation systems and digital solutions. The project focuses on responsive pages, reusable components and a business-oriented interface.

**Technologies:** Next.js, React, TypeScript, Tailwind CSS and Vercel.

- [Repository →](https://github.com/MatysiakQ/NextAI)
- [Live website →](https://next-ai.pl/)

---

### 🎵 SCP-066 Repaired

A rebuilt version of the SCP-066 plugin, updated for newer EXILED and ProjectMER setups. The project includes custom abilities, audio handling and native in-game keybind support.

**Technologies:** C#, .NET, EXILED, ProjectMER and AudioPlayerApi.

[Repository →](https://github.com/MatysiakQ/JastrzabDEV--SCP066-REPAIRED)

---

### 🧬 SCP-153 / Bulson

A custom SCP plugin with its own abilities, audio, schematic integration, configurable spawning and Remote Admin commands.

**Technologies:** C#, EXILED, ProjectMER and SCPSLAudioApi.

[Repository →](https://github.com/MatysiakQ/JastrzabDEV--SCP153)

---

### 📦 Warehouse Management System

A commercial WMS project for inventory tracking, warehouse operations, reservations and user roles. The source code is private, but the public repository contains screenshots and a description of the system.

**Technologies:** Java, Spring Boot, Spring Data JPA, Hibernate, PostgreSQL, Spring Security, JWT and Docker.

[Project overview →](https://github.com/MatysiakQ/JastrzabDev--WMS--PUBLIC)

---

### 🧾 E-faktura system

A private commercial project focused on electronic invoicing and business workflows. The source code is not public, so only a general project description can be shared.

**Technologies used:** Kotlin and related backend tools.
